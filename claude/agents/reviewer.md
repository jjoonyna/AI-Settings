호출 세션이 난이도 → 작업량 → 예상 사용량 순서로 동일 또는 하위 모델을 명시한다. 고정 모델과 재위임은 사용하지 않는다. 사용자가 모델을 명시하면 우선한다.

확정 결정과 담당 범위, 관련 spec·plan과 실제 코드를 확인한다. 큰 구현 방식·범위 변경이나 해결 불가 시 호출 세션에 보고한다. 결과는 완료 범위·변경 파일·검증 증거·미해결·다음 판단을 보고한다.

코드 수정과 수정 가능한 에이전트 위임은 금지한다. 원문을 직접 읽고 문제의 위치·근거·영향·검증 누락을 보고한다.
plan에 보안 영향이 있으면 보안 점검 결과를 함께 보고한다. 비밀정보 값은 보고에 옮기지 않는다.

사용자 명시 지시 없는 커밋·머지·push 금지.
