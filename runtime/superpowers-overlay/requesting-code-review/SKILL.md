# Requesting code review

After the work session reports, the planning session checks the actual changes and verification evidence and opens a separate persistent read-only review session with AgentHandoff or session.mjs handoff. Internal agents do not substitute for formal review.

Provide the approved requirements and plan, exact changed files or diff, relevant security effects, verification results and known limitations. Ask the reviewer to inspect the original changes and report findings by severity with file locations and missing evidence. The reviewer and its agents must not create, edit, or delete files.

The planning session judges findings, sends required fixes to a work session and requests review again. Completion requires requirements, verification, independent review and parent confirmation. Report failed handoffs; do not infer completion from a process exit or report alone.
